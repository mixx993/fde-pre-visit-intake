# FDE 信息预收集 skill 安装说明


一、这是什么
这是一个给 AI 工具用的“技能包”（英文叫 skill）。装好以后，您只要对 AI 说“帮我填上门前信息表”，
它会一个一个问您问题，经您同意后查看电脑配置，最后自动生成填好的 Excel 表。
大约 20 分钟，可以随时停，下次接着填。

二、安装（选一种）
1. 用 Claude Code 的：
   把压缩包里的 fde-pre-visit-intake 文件夹整个复制到
   Windows：C:\Users\<您的用户名>\.claude\skills\
   Mac：    ~/.claude/skills/
   复制完以后，文件夹里应该能看到 SKILL.md。重新打开 Claude Code。

2. 用其他支持“技能（skill）”的 AI 工具：
   按该工具的说明，把 fde-pre-visit-intake 文件夹放到它的技能目录。

3. 工具不支持技能，或者不确定的：
   把 fde-pre-visit-intake 文件夹放在任意位置（比如桌面），打开 AI 工具后发一句：
   “请读取 <文件夹位置>\SKILL.md，按里面的说明帮我填上门前信息表。”

三、开始
对 AI 说：帮我填上门前信息表

四、安全说明
- 不需要、也请不要告诉 AI 任何账号的密码。
- 查看电脑时只读：只看系统版本、配置、装了哪些软件，不看文档、聊天记录和浏览器记录，
  不安装、不修改、不删除任何东西。每次查看前，AI 会先告诉您要看什么，您同意了才会看。
- 所有结果只保存在您桌面的“上门前信息表”文件夹里，不会自动发出去。
  填好后，请您自己把 Excel 和录屏、截图通过网盘或 U 盘发给我们（不要用微信发原始文件）。

有问题随时联系您的对接人。
